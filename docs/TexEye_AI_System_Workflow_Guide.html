3. Overall System Workflow (End-to-End)

  1. Session Start: The operator mounts a fabric roll onto the unwinding stand, opens the mobile app, and scans the roll's QR code. This creates a new inspection session with roll details (Roll ID, Fabric Type, Width).
  2. Continuous Sensing: The fabric starts rolling. The industrial camera captures continuous frames under controlled LED illumination, while a rotary encoder tracks physical fabric movement down to the millimeter.
  3. Data Reliability Guard: Before running AI, the edge computer verifies four conditions: camera connection active, lighting brightness within threshold, image sharp (no blur), and zero dropped frames.
    • If Reliable: The frame proceeds directly to the AI vision model.
    • If Unreliable (Fault): A physical relay actuates the amber stack light and floor buzzer, and the fabric distance $[L_1, L_2]$ is logged as UNINSPECTED (never assumed defect-free!).
  4. AI Vision & Location Mapping: The YOLO model detects defects (holes, stains, weaving faults) and generates bounding boxes. The multi-frame tracker deduplicates detections across consecutive frames, and the rotary encoder translates frame coordinates into real physical roll coordinates: $X$ across width (cm) and $Y$ along length (m).
  5. Local Edge Saving: Defect records and uninspected spans are immediately saved to the local SQLite database. This guarantees zero latency and ensures inspection never stops if internet fails.
  6. Cloud Synchronization: If internet is available, batches are sent via HTTPS REST and WebSockets to the central server. If internet is down, records buffer safely in an offline outbox queue and automatically sync when restored.
  7. Quality Management & Result: The Quality Manager opens the web dashboard, inspects the 2D Digital Fabric Map, verifies ASTM D5430 4-point penalty grades, and exports the final PDF Quality Inspection Certificate.

5. Backend Architecture

The backend is divided into two focused operational layers:

  • Edge Processing Node (On-Premises Inspection Stand):
    • Camera Ingestion & GPIO Driver: Grabs frames from camera and reads hardware interrupt pulses from rotary encoder.
    • Inspection Reliability Monitor: Evaluates Laplacian blur variance and illumination threshold to detect failures.
    • YOLO AI Detector & Multi-Frame Tracker: Inferences defect bounding boxes and deduplicates detections.
    • Local Sync Daemon: Manages the SQLite transactional outbox queue and image sync dispatcher.
  • Central Server Node (FastAPI Cloud / On-Premises Server):
    • REST Ingestion Gateway: Exposes authenticated endpoints (/api/v1/sync/batch) to receive roll data and crops.
    • WebSocket Event Hub: Broadcasts live defect notifications to connected web and mobile clients.
    • ASTM D5430 Calculator: Computes penalty points based on physical flaw length and assigns roll quality grade.
    • PDF Report Engine: Compiles official inspection certificates with summary tables, defect maps, and verification hashes.

7. User Roles & Use Cases

  • Floor Operator (Mobile App): Mounts roll, scans QR tag to start inspection, receives buzzer/vibration alerts on critical flaws, pauses line if necessary, submits manual tags for unobservable flaws (e.g. shade variation).
  • Quality Inspector (Web Dashboard): Reviews flagged defect crop pictures, confirms or corrects AI classifications, visually checks uninspected sections.
  • Quality Manager (Web Dashboard): Reviews final ASTM D5430 roll scorecard (Grade A, B, or Scrap), approves inspection reports, and downloads signed PDF certificates.

8. Key Questions Your Supervisor Might Ask (With Confident Answers!)

Q1: "Why do you need both an edge computer and a central server? Why not do everything in the cloud?"
Answer: "Sir, fabric mills in Pakistan often face unstable internet connections. If we depended on the cloud for real-time video inspection, a temporary internet drop would stop the entire factory line. With our edge design, camera capture, encoder counting, and AI detection run locally in real time and save to a local SQLite buffer. Even during an internet blackout, inspection never stops. Once internet returns, data automatically synchronizes to the central server."
Q2: "How do you know the exact physical location of a defect on a moving roll?"
Answer: "Sir, we couple an industrial rotary optical encoder to the fabric roller. As fabric moves, the encoder generates electrical pulses proportional to displacement. Our edge code converts these pulses into physical length in meters ($Y$). Meanwhile, the bounding box pixel coordinate across the camera image is mapped to physical width in centimeters ($X$) using pre-calibrated millimeter-per-pixel scaling."
Q3: "What happens if the lighting fails, camera disconnects, or image is blurry?"
Answer: "Sir, this is a core innovation of TexEye AI called the Inspection Reliability Guard. If lighting drops below 800 lux, camera frames freeze, or blur variance drops, the system triggers an amber stack light and buzzer. Crucially, it records the exact fabric interval $[L_1, L_2]$ as UNINSPECTED. Our system will never mark an uninspected section as clean fabric, completely preventing false-clear errors."
