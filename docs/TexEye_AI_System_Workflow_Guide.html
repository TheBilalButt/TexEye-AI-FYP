1. Executive Overview & Proposal Baseline Core FYP Identity

Real-World Problem Solved: Manual textile inspection at commercial speeds (20-60 m/min) misses up to 40% of critical fabric flaws, causing immense fabric wastage, customer returns, and revenue loss. Furthermore, existing automated solutions fail silently during camera disconnections, poor factory illumination, or dropped frames, letting flawed fabric pass as first-grade. TexEye AI guarantees 100% inspection reliability by combining YOLO computer vision, rotary encoder metric tracking, real-time sensor guards that flag uninspected spans, offline SQLite buffering, and automated ASTM D5430 4-point grading.

9. Anticipated Supervisor Questions & Defense Script COMSATS FYP Meeting Prep

Q1: How does your system calculate the exact location of a defect on moving fabric?
Answer: "Sir, we combine two physical measurements: Across the fabric width (X coordinate), our camera lens is calibrated so each pixel corresponds to a fixed millimeter width. Along the fabric length (Y coordinate), an optical rotary encoder (1000 pulses per revolution) is mounted directly to the idler roller. As fabric unwinds, each encoder pulse represents exactly 0.2 mm of movement. When YOLO detects a flaw in frame N, we read the current pulse accumulator to compute the exact meter position along the roll."
Q2: How do you prevent counting the same defect multiple times across consecutive video frames?
Answer: "Sir, because the camera captures at 30 to 60 FPS, a single defect remains visible across 10 to 20 consecutive frames. We implement a multi-frame Kalman filter tracker. The tracker projects the expected position of the flaw based on current roller speed. Consecutive detections matching the same trajectory within a spatial gating threshold are merged into a single unique defect entity."
Q3: What happens if factory lighting fluctuates or the camera cable is accidentally disconnected?
Answer: "Sir, this is our core innovation: the Hardware & Inspection Monitoring Module. We continuously compute mean luminance (lux) and Laplacian variance (blur) on incoming frames. If lux drops below 800 or frames drop, the system immediately trips an amber stack light relay, sounds a warning buzzer, and logs an uninspected span [Y_start, Y_end] in SQLite. We never let uninspected fabric pass silently."
Q4: What if the factory loses internet connection during a 500-meter roll inspection?
Answer: "Sir, our architecture is 100% Offline-First. The inspection stand PC runs a local SQLite WAL database. Every defect coordinate, uninspected interval, and high-resolution JPEG crop writes to local NVMe storage with zero delay. A background sync daemon continuously checks connectivity; once the link is restored, it drains the outbox queue to the cloud server with zero production halt."
Q5: How does the ASTM D5430 4-Point grading system actually work?
Answer: "Sir, the standard ASTM D5430 assigns penalty points based on defect length: 1 point for flaws ≤ 3 inches (75 mm), 2 points for 3-6 inches (75-150 mm), 3 points for 6-9 inches (150-230 mm), and 4 points for flaws > 9 inches or holes > 1 inch. No single meter can exceed 4 points. The engine computes Total Points per 100 Square Meters: (Total Points × 10,000) / (Length × Width). If points ≤ 20, it is Grade A; if ≤ 40, Grade B; otherwise Scrap."
Q6: Can a quality inspector override an AI classification if the model makes a mistake?
Answer: "Sir, yes. On the Web Dashboard (Screen S-08: Defect Review Gallery), the inspector can zoom into high-res crop images, use digital electronic calipers to verify flaw dimensions, and select a corrected defect class from a dropdown. This updates the database and creates an immutable audit trail entry recording who modified the record and at what timestamp."
Q7: Why did you split the system into an Edge Stand Backend and a Central Cloud Backend?
Answer: "Sir, physical fabric inspection is an ultra-low-latency real-time task requiring 30 FPS inference and microsecond encoder interrupts. Cloud networks suffer from latency spikes and outages. By delegating real-time sensing, AI detection, and safety relays to a local Stand PC, we achieve 100% reliability, while the central cloud backend provides centralized reporting, multi-user web access, and ERP integration."
