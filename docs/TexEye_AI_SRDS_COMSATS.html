1 Introduction

1.1 System Introduction

TexEye AI: AI-Based Fabric Defect Detection and Quality Management System is an autonomous, cyber-physical inspection platform engineered to eliminate human error, visual fatigue, and unrecorded defects in high-speed industrial textile manufacturing. By coupling an industrial area-scan camera and a quadrature rotary optical encoder with edge AI deep learning (YOLOv8/v11 optimized via NVIDIA TensorRT), TexEye AI continuously scans moving fabric webs at velocities up to 60 meters per minute.

The platform executes sub-millimeter longitudinal flaw tracking, enforces strict optical-metrological reliability invariants, automates the international ASTM D5430-07 4-point fabric quality grading standard, and persists auditable digital records across a mobile floor application and a centralized web management dashboard.

1.2 Background and Problem Statement

In contemporary weaving and knitting mills, quality inspection is still predominantly conducted through manual human observation. Exhausted human inspectors watching fabric moving at 20 to 60+ m/min regularly miss 30% to 40% of small surface flaws (broken yarns, oil drops, slubs, needle holes). Furthermore, manual logging relies on handwritten paper logs that lack physical longitudinal coordinates, making defect excision in cutting rooms imprecise and causing severe financial chargebacks and export container rejections.

1.3 Objectives of the System

  • Real-Time Defect Segmentation: Detect, classify, and bound surface anomalies within 30 ms per frame.
  • Metric Displacement Synchronization: Map flaw coordinates (X mm, Y m) using rotary optical encoder pulses.
  • Inspection Invariant Guard: Actively monitor lux levels, camera frame delivery, and lens blur, flagging uninspected intervals on fault.
  • Automated ASTM D5430-07 Grading: Eliminate manual arithmetic, computing penalty points and commercial Grade A/B/C/Reject instantaneously.
  • Offline-Resilient Architecture: Buffer all defect crops and metrics locally on edge storage during factory network outages.

1.4 Industrial Significance

TexEye AI provides a transparent digital bridge between raw fabric production and garment apparel cutting rooms. By providing certified 2D defect maps and cryptographic SHA-256 inspection reports, mills prevent rejected shipment penalties, optimize cutting marker yields, and establish automated Industry 4.0 traceability.

2 Overall Description

2.1 Product Perspective

TexEye AI is an autonomous quality assurance system mounted directly above motorized rolling tables. It interfaces with physical sensing hardware (GigE camera, rotary encoder, 3-tier stack light) on the factory floor, while maintaining secure HTTPS synchronization with central enterprise servers and cloud storage.

2.3 Product Major Functions

TexEye AI is partitioned into five specialized, cohesive functional modules:

  • 1. AI Defect Detection and Metric Tracking Module: Real-time frame rectification, YOLO segmentation inference, Kalman tracking across frames, and metric (X, Y) coordinate estimation.
  • 2. Hardware and Inspection Monitoring Module: Hardware pulse counting, camera heartbeat tracking, illumination lux monitoring, lens blur evaluation, stack light / buzzer relay actuation, and uninspected span recording.
  • 3. Mobile Floor Application: QR code session registration, live line speed preview, real-time vibration alerts, defect crop viewer, and manual operator flaw tagging.
  • 4. Web Quality Management & Digital Fabric Map: Interactive 2D defect map, defect crop examination, flaw relabeling, uninspected span review, and ASTM D5430 scorecard rendering.
  • 5. Smart Operations Module: Automated 4-point commercial grading, cryptographic PDF certificate generation, warehouse inventory tracking, scrap segregation, and plant defect Pareto statistics.

UC-OP-01: Start Roll Inspection Session
Primary ActorFloor Operator (Secondary: Industrial Edge Unit)
PreconditionsStand powered, lighting active, camera/encoder recognized by Linux kernel, operator signed in.
PostconditionsSession initialized in SQLite WAL with status IN_PROGRESS, pulse accumulator zeroed (Y = 0.00 m).
Main Success Scenario1. Operator mounts fabric roll onto rollers and threads web through optical zone.
2. Operator opens Mobile App, selects 'Start New Roll', and scans roll QR code.
3. App sends start request to edge unit via local Wi-Fi REST API (POST /api/v1/session/start).
4. Edge unit resets rotary encoder hardware pulse accumulator to zero.
5. Edge unit verifies lighting lux and camera frame delivery; confirms operating environment.
6. Edge unit creates new session in SQLite (WAL) and transitions mobile app to Live Monitor.

4.2 Safety and Security Requirements

Safety Requirements: All GPIO circuits are optically isolated (≥ 2.5 kV RMS rating) to prevent electrical ground loops (SR-01). Alarm relays are wired in fail-safe mode, automatically tripping on edge power loss (SR-02). Optical sensors maintain non-contact operation with moving fabric (SR-03). The LED array complies with IEC 62471 photobiological safety standards (SR-04). An emergency stop handshake provides an isolated dry-contact interlock wired directly to the winding table emergency stop circuit (SR-06).

Security Requirements: System access enforces Role-Based Access Control (RBAC) via signed JWT tokens (SC-01). Passwords are encrypted using Argon2id with per-user cryptographic salts (SC-02). All client-server and edge-cloud traffic mandates TLS 1.3 encryption (SC-03). Finalized certificates embed a SHA-256 digital signature over roll metadata and ASTM points (SC-04). Every inspector relabeling action and grading override is permanently recorded in an immutable PostgreSQL audit trail (SC-05).

4.3 Software Quality Attributes

Reliability Invariant: A fabric roll shall never be certified as defect-free if any segment traversed the inspection zone during an unmonitored or optically degraded state. Dual-storage fault tolerance guarantees that every defect event is committed to local SQLite WAL storage prior to network transmission, ensuring zero data loss during power outages or Wi-Fi drops.

5.6.2 System Algorithms

This section details the primary algorithms governing metric coordinate tracking, safety gating, and automated ASTM D5430 4-point penalty accumulation:

Algorithm 5.1: Encoder Quadrature Metric Coordinate Tracker
Input: Delta_P (quadrature pulse delta), PPR = 1024, D_roller = 50.0 mm (diameter)
Output: Y_current (absolute longitudinal meters along fabric roll)
1: Resolution_mm_per_pulse = (pi * D_roller) / (4 * PPR)
2: Distance_delta_mm = Delta_P * Resolution_mm_per_pulse
3: Y_current = Y_previous + (Distance_delta_mm / 1000.0)
4: Return Y_current
Algorithm 5.2: Real-Time Lighting & Motion Blur Invariant Guard
Input: Frame I (grayscale image), v_fabric (current fabric speed in m/s)
Output: Status in {RELIABLE, FAULT_LIGHTING, FAULT_BLUR, FAULT_OVERSPEED}
1: Mean_Illuminance_Lux = ComputeMeanPixelIntensity(I) * LuxCalibrationFactor
2: If Mean_Illuminance_Lux < 800: Return FAULT_LIGHTING
3: Blur_Score = VarianceOfLaplacian(I)
4: If Blur_Score < 100.0: Return FAULT_BLUR
5: If v_fabric > 0.50: Return FAULT_OVERSPEED
6: Return RELIABLE
Algorithm 5.3: Multi-Frame Kalman Defect Associator
Input: ActiveTracks T, Detections D = {b_1, b_2, ... b_k}, IoU_Threshold = 0.45
Output: UpdatedTracks T_updated, NewDefectRecords R_new
1: For each track t in T: Predict Kalman state [x, y, vx, vy] forward by dt
2: CostMatrix = Compute_IoU_Distance_Matrix(T, D)
3: Matches, UnmatchedDetections, UnmatchedTracks = LinearAssignment(CostMatrix, IoU_Threshold)
4: For each (t, d) in Matches: UpdateKalman(t, d.bbox)
5: For each d in UnmatchedDetections: CreateNewTrack(d)
6: For each t in UnmatchedTracks: If t.missed_frames > 3: FinalizeAndSaveDefect(t); Remove(t)
7: Return T_updated, R_new
Algorithm 5.4: ASTM D5430 4-Point Penalty Accumulator
Input: DefectList D, RollLength_Meters L, FabricWidth_Meters W
Output: TotalPoints, PointsPer100SqMeters, FinalGrade in {Grade A, Grade B, Grade C, Reject}
1: Partition roll length into 1-meter linear bins: Bins = [0 to 1m, 1 to 2m, ..., L-1 to Lm]
2: For each defect d in D:
3:     L_mm = d.physical_length_mm
4:     Points = (1 if L_mm <= 75 else (2 if L_mm <= 150 else (3 if L_mm <= 230 else 4)))
5:     If d.type == HOLE: Points = (2 if d.diameter_mm <= 25.0 else 4)
6:     Bin_Index = Floor(d.coord_y_m); Bins[Bin_Index].accumulate_points(Points)
7: For each bin b in Bins: b.points = Min(b.points, 4) // ASTM 4-point linear meter cap
8: TotalPoints = Sum(b.points for b in Bins); Area_SqM = L * W
9: PointsPer100SqM = (TotalPoints * 100.0) / Area_SqM
10: If PointsPer100SqM <= 20.0 and NoUninspectedSpans: FinalGrade = "Grade A"
11: Else if PointsPer100SqM <= 28.0: FinalGrade = "Grade B"
12: Else if PointsPer100SqM <= 40.0: FinalGrade = "Grade C"
13: Else: FinalGrade = "Reject"
14: Return TotalPoints, PointsPer100SqM, FinalGrade
