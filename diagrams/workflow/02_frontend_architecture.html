📝 How to Draw and Explain Frontend Architecture to Your Supervisor:

1. Two Separate Client Applications Explain: "Sir, we have two clients tailored for distinct floor roles: A Flutter Mobile App for the floor operator moving along the stand, and a React Web Dashboard for the quality manager in the inspection office."
2. Real-Time WebSocket Alerts Explain: "Sir, when the AI model detects a defect, the operator does not refresh the page. A WebSocket event triggers instant haptic vibration on the mobile phone and displays a high-contrast alarm modal."
3. Interactive 2D Map & ASTM Grading Explain: "The manager sees the entire fabric roll rendered on an HTML5 canvas map with exact metric locations (X cm, Y m), uninspected spans, and an automated ASTM 4-point scorecard ready for PDF certificate export."
