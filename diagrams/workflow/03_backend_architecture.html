📝 How to Draw and Explain Backend Architecture to Your Supervisor:

1. Stand Edge Backend (Left Box) Explain: "Sir, on the inspection stand itself, we run a lightweight local Python backend. It handles real-time tasks: camera frames, rotary encoder pulses, YOLO defect inference, and local SQLite caching."
2. Central Cloud Backend (Right Box) Explain: "Sir, in the cloud or factory server, we run a FastAPI server. It receives synced batches, manages PostgreSQL and MinIO storage, runs the ASTM D5430 grading engine, and generates PDF certificates."
3. Complete Edge Autonomy Explain: "Even if the network cable to the cloud server is cut, the stand edge backend never halts. It continues inspecting fabric, triggers local stack lights, and saves records into SQLite."
